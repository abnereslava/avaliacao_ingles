# Avaliação de Inglês — Teens 1–4

Avaliação digital responsiva com 30 questões de múltipla escolha, baseada nos conteúdos das apostilas Teens 1–4 (A1–A2).

## Estrutura

- 30 questões, uma por tela
- 4 alternativas por questão
- Barra de progresso
- Navegação anterior/próxima
- Mapa de questões respondidas
- Progresso salvo no navegador durante a realização
- Validação de questões não respondidas antes do envio
- Correção automática
- Resultado geral e desempenho por bloco (Teens 1, 2, 3 e 4)
- Layout responsivo para celular, tablet e desktop
- Sem frameworks ou dependências externas

## Executar

Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor HTTP estático.

## Publicação

Por ser um projeto estático, pode ser publicado em GitHub Pages, Cloudflare Pages, Netlify, Vercel ou serviço equivalente.

## Observação sobre uso em avaliações reais

O gabarito está no JavaScript do cliente para permitir correção automática sem backend. Em uma aplicação de prova com necessidade de maior controle, a correção e o armazenamento das respostas devem ser movidos para um backend ou serviço de formulários.
